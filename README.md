# ComfyUI-JG-GPT-Img2 插件 - AI剑歌

这是一个包含 GPT Image 2 相关节点的 ComfyUI 插件，支持百度翻译和提示词优化功能。

## 包含的节点

### 1. GPT_Image_2_异步
- **功能**：GPT Image 2 图像生成/编辑（文生图、图生图）
- **特点**：异步模式，支持多种输出格式，适合常规使用
- **参考图数量**：1-20 张（动态调整）
- **使用场景**：日常图像生成和编辑，支持文生图和图生图两种模式

### 2. GPT_Image_2_官方稳定版
- **功能**：GPT Image 2 官方稳定版节点
- **特点**：使用官方 API，稳定性高，支持遮罩编辑
- **参考图数量**：1-20 张（动态调整）
- **使用场景**：需要高稳定性的生产环境，支持异步/同步模式切换

### 3. GPT_Image_2_官方4K
- **功能**：GPT Image 2 官方 4K 版本
- **特点**：支持最高 4K 分辨率（3840x2160），通过画面比例+分辨率组合选择
- **参考图数量**：1-20 张（动态调整）
- **使用场景**：需要高分辨率输出的场景

### 4. GPT_Image_2_综合
- **功能**：GPT Image 2 综合版（支持对话历史）
- **特点**：支持多轮对话，自动关联上一轮生成结果
- **参考图数量**：1-20 张（动态调整）
- **使用场景**：需要迭代生成、逐步优化的创意工作流

### 5. GPT_智能对话
- **功能**：GPT 智能对话节点
- **特点**：纯文本对话，可输入参考图进行分析
- **参考图数量**：1-20 张（动态调整）
- **使用场景**：图像分析、文案生成、创意讨论

### 6. ⚔️ 提示词翻译/优化
- **功能**：翻译中文提示词为英文，或进行优化
- **模式**：
  - `translate` - 仅翻译中文到英文
  - `optimize` - 优化提示词（需要 GPT API）
  - `both` - 先翻译，再优化
- **使用场景**：提升英文提示词质量，获得更好的生成效果

### 7. ⚔️ 配置管理
- **功能**：查看配置状态和说明
- **使用场景**：检查百度翻译和提示词优化 API 的配置状态

## 安装方法

1. 将此文件夹复制到 ComfyUI 的 `custom_nodes` 目录中
2. 重启 ComfyUI

## 配置说明

### 1. 创建配置文件

1. 复制 `conf/jg_config.example.json` 为 `conf/jg_config.json`
2. 填入你的 API 密钥：

```json
{
  "baidu_translate": {
    "APP_ID": "你的百度翻译API APP_ID",
    "SECRET_KEY": "你的百度翻译API SECRET_KEY",
    "timeout": 10
  },
  "prompt_optimize": {
    "api_key": "你的GPT提示词优化API密钥",
    "base_url": "https://api.bltcy.ai",
    "model": "gpt-4o-mini",
    "timeout": 30
  }
}
```

### 2. 获取 API 密钥

- **百度翻译 API**：访问 https://fanyi-api.baidu.com/
  - 注册并登录百度翻译开放平台
  - 创建应用获取 APP_ID 和 SECRET_KEY

- **提示词优化 API**：可使用柏拉图 API 或其他兼容的 GPT API
  - 可以直接使用已有的 GPT API Key（和节点中相同的 Key）

### 3. 验证配置

在 ComfyUI 中使用 **⚔️ 配置管理** 节点查看配置状态。

## 使用说明

### API 线路选择

- **柏拉图** - 默认推荐
- **zhenzhen** - 备用线路
- **hk** - 香港线路
- **us** - 美国线路
- **ip** - 自定义地址（需要在"自定义API地址"字段填写）

### 参考图数量动态调整

所有图像节点支持动态调整参考图数量（1-20张）：

1. 在节点中设置「参考图数量」参数
2. 连接点会自动增加或减少
3. 增加时：保留原有连接线，只新增空白连接点
4. 减少时：从最后一个连接点开始移除，保留前面的连接

### 主要功能

- **文生图** - 根据提示词生成图像
- **图生图** - 根据参考图和提示词编辑图像
- **支持多参考图** - 可以输入多达20张参考图
- **遮罩支持** - 支持遮罩编辑（官方稳定版、官方4K）
- **多种尺寸选项** - 支持多种分辨率和宽高比
- **种子控制** - 支持固定种子和随机种子
- **异步模式** - 支持异步轮询获取结果

### 节点分类

所有节点在 ComfyUI 的节点菜单中分类为 `🤖GPT-Image-2`。

### 输出说明

所有图像节点的输出：
1. **IMAGE** - 生成的图像张量
2. **图片链接** - 图片的 URL 地址
3. **响应信息** - 详细的生成信息（包含任务ID、参数等）
